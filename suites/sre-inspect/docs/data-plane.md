## Why this shape (ticket #146, decided 2026-08-27)

The reference implementation reached four data planes directly (three Prometheus endpoints with a
basic-auth header derived from a cloud access key, an observability MCP sidecar with the key, a
CloudMonitor toolset that had been returning 403 for a month, and a 93 MB CLI mounted into the
container for index/DTS lookups). A department joining needed a cloud RAM policy, three secrets
and an MCP allow-list. With everything behind Grafana, joining = one service-account token + the
list of datasource names.

## mcp-grafana sidecar (measured 2026-08-28 against the image, not the README)

- `grafana/mcp-grafana:1.2.0@sha256:cfae68f893dbe40cb6df69579f78beb226f973ded4436d47c844f91d2f00dc53`
  runs as uid 1000, ships no shell tools (no in-container healthcheck), and its entrypoint hard-codes
  `--transport sse --address 0.0.0.0:8000` → compose overrides `entrypoint`.
- Flags: `-t stdio|sse|streamable-http`, `-address`, `-endpoint-path /mcp`, `-disable-write`,
  `-enabled-tools` with **singular** categories (`datasource,prometheus,alerting,dashboard,navigation,search`),
  `-grafana-timeout 60s` (default 10s is too short for SLS-backed Prometheus), `-allowed-hosts`,
  `-server-auth-token` (or env `MCP_GRAFANA_SERVER_TOKEN`; an unauthenticated non-loopback listener
  logs an ERROR and "will become a startup error").
- 19 tools with that category set; all six Prometheus tools work against SLS-workspace Prometheus
  endpoints (`AliyunEcs_*`, `nsq_*` …).
- Holmes reaches it over streamable-http with `extra_headers: {Authorization: "Bearer {{ env.MCP_GRAFANA_SERVER_TOKEN }}"}`;
  Claude Code / Codex run it as a stdio process (`run mcp-config`).
- Two Host checks stack on the HTTP transports: mcp-grafana's `--allowed-hosts` (exact `host:port`
  strings, `*` disables) **and** the embedded mcp-go server's localhost protection, which rejects any
  request arriving over a *loopback* connection whose `Host` is not a localhost value
  (`Forbidden: invalid Host header "…"`). Cross-container callers (Holmes → `grafana-mcp:8000`) only
  meet the first; a probe run inside the sidecar's own network namespace meets the second — use a
  container on the compose network, not `--network container:…`, when testing.

## SLS through `/api/ds/query` (plugin `aliyun-log-service-datasource`, backend `pkg/sls-plugin.go`)

Query model per `refId`: `{"datasource":{"uid"},"type":"all","query","xcol":"","ycol":"","logsPerPage":100,
"currentPage":1,"totalLogs":N,"queryType":"range","powerSql":false,"logStore":"<override>"}`;
`from`/`to` as epoch-ms strings or relative. Backend behaviour: `totalLogs` clamped to [1, 5000] and
paged by 100 with `Reverse=true`; no `|` → logs frame (`time`, `message`, one column per field);
`|` → table frame, every value typed string; `Progress != Complete` → error `incomplete logs, you
can switch to powerSql`; `logStore`/`logstore` both accepted; colon keys in the search segment are
**not** quoted on this path. Errors are the SLS JSON (`ParameterInvalid` …) inside `results.A.error`,
which `sls_query.py` prints verbatim as `error: …`. Details and the error table: `skills/grafana-sls`.

## Removed / kept (relative to the reference instance)

Removed: the three direct Prometheus instances + basic-auth secret, the CloudMonitor toolset, the
observability MCP sidecar (+ its 26-tool allow-list), the DTS and SLS CLI toolsets, the CLI binary
and plugin mounts, every `ALIBABA_CLOUD_*` variable.
Kept: `bash` (core allow-list; needed to read spilled results), `internet`, the query methodology
(now `skills/grafana-sls`), index snapshots as **offline artefacts** generated by whoever holds a
cloud key and shipped inside the department instance.

## Credential model

`env/.env.holmes` (0600, gitignored by the workspace's `.env.*` rule) carries `GRAFANA_URL`,
`GRAFANA_SERVICE_ACCOUNT_TOKEN`, `GRAFANA_ORG_ID`, `MCP_GRAFANA_SERVER_TOKEN` (+ LLM/API keys for
the optional Holmes). Token rights: Viewer is enough on OSS; on Enterprise/RBAC narrow
`datasources:query` to the tenant's datasource uids. `run doctor` shows presence and length only;
`run finish` refuses to write a report containing a token-shaped string; the toolset guard refuses
any credential shape on a Holmes command line.
